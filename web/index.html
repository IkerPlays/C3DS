Todo lo que necesitas para tu primer juego

Editor visualEscenas, objetos, cuadrícula, zoom, deshacer y rehacer. Arrastra y redimensiona en las dos pantallas.
Vista previa al instanteJuega mientras editas con teclado, ratón o los botones en pantalla. Mismo motor que el juego exportado.
Sprites y sonidoImporta PNG, JPG, WebP, WAV, OGG o MP3. Se convierten solos a los formatos de la 3DS.
Lógica sin códigoReglas “cuando pase esto → haz esto”: botones, colisiones, toques, bordes, variables y temporizadores.
.3dsx y .cia realesExporta un proyecto C listo para compilar, o compílalo en la nube y descarga los archivos.
Importa Unity, Godot y UnrealAnaliza tu proyecto, mide los límites de la 3DS y convierte texturas y audio para reutilizarlos.

Cómo funciona

  1. 1
    Crea

    Elige una plantilla o empieza en blanco. Coloca objetos, sprites y textos en la pantalla superior e inferior.

  2. 2
    Prueba

    Pulsa ▶ Probar: tu juego corre en el navegador con los mismos controles de la consola.

  3. 3
    Exporta

    Descarga el proyecto 3DS (make → .3dsx, make cia → .cia), un HTML5 o un .exe de Windows.

  4. 4
    Juega

    Copia el .3dsx a la SD o instala el .cia con FBI. También funciona en el emulador Azahar.

Sobre el proyecto

C3DS nace para que hacer un juego de 3DS no requiera montar un toolchain ni saber C. El editor genera un proyecto de devkitARM + libctru + citro2d y lo compila con herramientas abiertas (tex3ds, makerom, bannertool).

Es una versión alfa: lo que ves funciona y está probado en el CI, pero aún hay mucho por hacer.

  • Actualizaciones automáticas dentro de las apps

Honestidad por delante

  • Unity, Godot y Unreal no se convierten tal cual (no existe runtime para la 3DS): se reutilizan los assets y se rehace la lógica.
  • Un .exe de Windows no se puede pasar a 3DS: solo se analiza.
  • El .cia compila en el CI pero aún no se ha probado en consola real.

Verificar la descarga

Cada release incluye SHA256SUMS.txt. Comprueba el archivo con sha256sum -c SHA256SUMS.txt (Linux/macOS) o Get-FileHash archivo.exe (Windows).

Notas de instalación

  • Windows: si SmartScreen avisa, “Más información → Ejecutar de todas formas” (el instalador no está firmado).
  • macOS: la app no está notarizada: clic derecho → Abrir la primera vez.
  • Android: permite instalar apps de este origen. Es un APK de depuración.
  • iOS: el IPA no está firmado; instálalo con AltStore, Sideloadly o Xcode.
  • Linux: chmod +x *.AppImage y ejecútalo, o instala el .deb.
