    Límites de la Nintendo 3DS

    Valores orientativos. El analizador y el editor los usan para avisarte.

    Estado del proyecto

    • Analizador de proyectos Unity / Godot / Unreal / .exe (en el navegador)
    • Editor básico → proyecto C para 3DS (.3dsx vía devkitPro)
    • Compilación en la nube de .3dsx y .cia desde la web
    • Conversión automática de assets (texturas .t3x, audio, modelos)
    • Apps nativas: Windows, macOS, Linux, Android, iOS

    Importante: ningún motor (Unity, Godot, Unreal) puede exportarse tal cual a 3DS y un .exe x86/x64 no puede convertirse a ARM11. C3DS analiza qué es reutilizable (assets) y qué hay que portar (código), y te da una base compilable.
