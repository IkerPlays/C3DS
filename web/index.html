Estado del proyecto

  • Editor visual: escenas, sprites, sonido, variables, reglas, botones táctiles
  • Vista previa con el mismo motor que el exportador HTML5
  • Guardado automático en el navegador, deshacer y rehacer
  • Exportar proyecto 3DS (.zip) → .3dsx y .cia con devkitARM
  • Compilación en la nube (si el sitio tiene el token configurado)
  • Exportar juego HTML5; analizador y conversor de assets de Unity/Godot/Unreal
  • Apps: Windows, macOS, Linux (Tauri) · Android, iOS (Capacitor)
  • Exportar a Windows .exe desde el editor
  • Actualizaciones automáticas dentro de las apps (hoy: aviso de nueva versión)

Ningún motor (Unity, Godot, Unreal) puede exportarse tal cual a 3DS, y un .exe x86/x64 no puede convertirse a ARM11. C3DS analiza qué assets sirven, los convierte, y te da una base compilable.
